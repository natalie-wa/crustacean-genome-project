Definitions, source records, and the scope of the Genome Explorer.

Source and scope

The first release uses the project’s uploaded crustacean_genomes(2).xlsx workbook, containing 410 NCBI assembly records. The original query and retrieval date are not recorded in the workbook. The dashboard is a frozen view of that input and does not query NCBI when a visitor opens the page. Accession links lead to the current NCBI records.

What the counts mean

  • Assembly records count input rows. GenBank and RefSeq pairs, alternate assemblies, and haplotypes are retained. These are not counts of independent biological genomes.
  • NCBI taxon IDs count distinct organism taxonomic identifiers. Unresolved taxa are retained. This is not a verified count of accepted species.
  • Families and higher groups retain the workbook’s labels, with surrounding whitespace trimmed. Synonyms and ranks have not been reconciled against an accepted taxonomic reference. For example, some source order labels may be nested within other source groups.
  • Assembly levels retain NCBI’s labels. “Chromosome” does not establish independently validated chromosome counts or completeness. “Complete Genome” does not by itself establish a nuclear assembly.

Records needing review

Records shorter than 100,000 bp receive a scope-review flag. This threshold is a screening aid, not proof of organellar origin, and does not detect every incomplete or non-nuclear assembly. Organism names containing “sp.”, “cf.”, or “aff.” receive an unresolved-taxon flag. All records are included by default; the explorer provides optional filters for these review flags.

Interpreting gaps

Remipedia, Cephalocarida, Branchiura, and Mystacocarida are included as comparison groups from the project’s review framework. The absence of a matching class label indicates no record in this input, not a verified absence from all public repositories. The comparison groups are not an exhaustive taxonomic backbone.

Coverage percentages and counts of unsequenced species require validated denominators. A future release can reconcile accepted families, genera, and species against a documented reference such as WoRMS, then compare the resulting taxonomy with an updated assembly inventory. No denominator is assumed in this release.

Updating the explorer

The repository separates source data, page content, styles, assets, and build scripts. Replacing the input CSV and rebuilding updates the dashboard without editing its charts. A workbook import script supports the current input format. The source README explains the update and GitHub Pages workflow.

Attribution

These resources were produced by the researchers and institutions identified in their NCBI records. Inclusion in this explorer does not imply that an assembly was generated by CrustGP. Please cite the original assembly, BioProject, and associated publication when using a resource.
